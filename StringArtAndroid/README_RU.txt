СТРИНГ-АРТ — ANDROID-ПРОЕКТ

Это Android-приложение-оболочка с генератором внутри. Сам генератор и его алгоритм
находятся в app/src/main/assets/index.html и работают локально в Android WebView.
Для выбора фотографии используется системный выбор изображений Android.

КАК ПОЛУЧИТЬ APK
1. Установите Android Studio на компьютер.
2. Распакуйте архив.
3. В Android Studio выберите Open и укажите папку StringArtAndroid.
4. Дождитесь Gradle Sync (первый запуск может потребовать интернет для загрузки зависимостей).
5. Выберите Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK появится в app/build/outputs/apk/debug/app-debug.apk.

ТРЕБОВАНИЯ
- Android 6.0 (API 23) или новее.
- Android Studio с Android SDK 35.
- Для сборки APK нужен компьютер; готовый APK в этой среде собрать не удалось,
  поскольку Android SDK/Gradle здесь не установлены.

ПРИМЕЧАНИЕ
Приложение использует встроенную локальную HTML-страницу и не требует сервера
для генерации портрета. Импорт фотографии выполняется через системный picker.


АВТОМАТИЧЕСКАЯ СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS
1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в репозиторий всё содержимое этой папки (включая скрытую папку .github).
3. Откройте вкладку Actions и запустите workflow "Build Android APK"
   (или сделайте push в main/master).
4. После завершения откройте запуск workflow и скачайте артефакт
   StringArt-debug-apk — внутри будет app-debug.apk.
Это debug APK для установки и тестирования, не подписанный релиз для Google Play.
